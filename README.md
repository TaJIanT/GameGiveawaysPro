# 🎮 GameGiveawaysPro

**GameGiveawaysPro** — это современное приложение для геймеров, которое автоматически отслеживает и собирает бесплатные раздачи игр со всех популярных платформ: **Steam, Epic Games, GOG, itch.io** и других!

## ✨ Главные возможности

*   🛒 **Все магазины в одном окне**: Поддержка Steam, Epic Games, GOG, а также сборник бесплатных ключей и промокодов.
*   🎯 **Тихий снайпер (Фоновый режим)**: Программа работает в системном трее и автоматически присылает звуковые уведомления, как только появляется новая раздача. Вы не пропустите ни одной игры!
*   ⚙️ **Полноценные настройки**: Выбирайте нужные платформы, настраивайте частоту проверок (от 15 минут до 2 часов) и управляйте автозагрузкой с Windows прямо из приложения.
*   💰 **Умный Калькулятор**: Подсчитывает общую стоимость всех текущих раздач, показывая, сколько денег вы экономите прямо сейчас.
*   ⚡ **Zero-Trace & CDN**: Никакого мусора на диске! Обложки игр проксируются, сжимаются "на лету" через открытый CDN и хранятся исключительно в оперативной памяти (строгий лимит в 100 изображений).
*   🔄 **Автообновление**: Встроенный апдейтер сам скачает и установит новую версию, если она появится на GitHub.

## 📥 Как скачать и установить?

Вам **не нужно** устанавливать Python или разбираться в коде!

1. Перейдите на страницу [Скачать (Releases)](https://github.com/TaJIanT/GameGiveawaysPro/releases/latest).
2. Скачайте файл \GameGiveawaysPro.exe\.
3. Запустите его (установка не требуется) и забирайте бесплатные игры!


## 🛠️ Технологии
*  💻 Что умеет десктопное приложение (GameGiveawaysPro)?Я делал программу для себя, поэтому хотел, чтобы интерфейс выглядел современно (никаких уродливых окон из 2000-х) и при этом потреблял минимум ресурсов (Zero-Trace концепция).
*   Все магазины в одном окне: Steam, Epic Games, GOG, а также сборники ключей и промокодов.  Тихий снайпер (Фоновый режим): Приложение сворачивается в системный трей и само проверяет раздачи по таймеру. Если нашла годнота — проигрывает звуковой сигнал и пришлет аккуратное уведомление.  Умный калькулятор выгоды: Считает суммарную стоимость всех текущих раздач и показывает, сколько долларов/рублей вы сэкономили.  Прямые ссылки на клиенты: Для Steam-игр программа умеет генерировать ссылки вида steam://store/app/..., открывая игру прямо в лаунчере Steam на компьютере.  Умный поиск и кэширование: Обложки подгружаются через быстрый CDN-прокси и не забивают диск мусором.
*   🤖 Облачный бот для Telegram (GitHub Actions)Самое интересное — это автоматизация для Telegram-канала. Мне не хотелось держать ради этого включенный компьютер 24/7.Решение нашлось элегантное: я написал скрипт на Python (telegram_poster.py), который запускается по расписанию через GitHub Actions (бесплатные облачные воркфлоу от GitHub).Как это работает под капотом:Раз в несколько часов GitHub запускает виртуальную машину в облаке.Скрипт обращается к открытым API (CheapShark и GamerPower), фильтрует только 100% бесплатные игры.  Сравнивает список с файлом истории notification_history.json (чтобы не спамить дубликатами).  Рандомизирует заголовки («🔥 ЛУТАЕМ ХАЛЯВУ», «🚨 СВЕЖИЙ ДРОП», «⚡️ СРОЧНО НА АККАУНТ») и префиксы цен.  Форматирует красивый HTML-пост с картинкой и генерирует две интерактивные кнопки: первая ведет на саму раздачу, вторая — промо-кнопка со ссылкой на скачивание десктопного трекера.  И всё это работает полностью автономно, потребляя 0 ресурсов моего ПК!
*   📥 Где скачать и посмотреть код?Проект полностью открытый (лицензия MIT), код чистый, без скрытых майнеров и прочей гадости.  📦 Скачать готовый .exe (установка не требуется): GitHub Releases
*   ⭐ Исходный код (если хотите запустить своего бота или доработать под себя): Репозиторий на GitHub  Если вы хотите запустить такого же Telegram-бота для своего канала, в репозитории есть вся необходимая структура (скрипт постера, конфиг для GitHub Actions и файл истории) — вам останется только добавить токены бота в секреты репозитория (Settings ➡️ Secrets ➡️ Actions).
